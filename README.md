# Retail Sales Performance Dashboard (Excel)

## Overview
This project analyzes retail sales data to evaluate revenue performance, sales trends, and product category behavior.  
The dashboard is designed to support business and merchandising decisions commonly used in retail analytics.

## Tools Used
- Microsoft Excel
- Pivot Tables
- KPI Cards
- Data Visualization

## Key Metrics
- Total Sales
- Total Units Sold
- Best Performing Month
- Monthly and Weekly Sales Trends
- Sales by Product Category

## Dashboard Features
- Interactive KPI cards summarizing overall performance
- Monthly sales and units trend analysis
- Weekly sales volatility visualization
- Category-level comparison of revenue vs units sold
- Clean layout optimized for business reporting

## Key Insights
- Sales peaked in May and October, indicating seasonal demand patterns  
- Electronics generated the highest revenue, while Clothing led in unit volume  
- Weekly sales volatility suggests promotion-driven purchasing behavior  

## Skills Demonstrated
- Retail sales analysis
- Time-series trend analysis
- KPI development
- Data cleaning and transformation
- Business-focused data visualization
